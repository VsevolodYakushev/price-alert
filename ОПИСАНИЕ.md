# Price Alert: описание проекта

**Price Alert** — приложение на C++, которое следит за ценами криптоактивов на бирже Binance. Когда цена опускается до цели, заданной пользователем, приложение присылает уведомление. Это курсовой проект команды из трёх человек.

## Проблема
Крипторынок работает круглосуточно, и цена может заметно измениться за несколько минут. Следить за графиком вручную неудобно, нужный момент легко пропустить. Price Alert следит за ценой сам и сообщает, когда она дошла до цели.

## Как это работает
1. Пользователь добавляет тикер в формате Binance, например `BTCUSDT`.
2. Задаёт цель — цену, до которой ждёт падения.
3. Когда цена опускается до цели, приходит алерт. Повторный алерт приходит только после того, как цена вернётся выше цели и снова опустится.

## Функционал версии 1
- **Вход в два этапа.** Логин и пароль, затем код подтверждения из письма. Есть регистрация с проверкой полей: формат email, длина пароля, совпадение паролей.
- **Портфель.** Добавление и удаление тикеров с проверкой формата.
- **Цель прямо в таблице.** Двойной щелчок по ячейке, Enter — сохранить, Esc — отменить.
- **Живая таблица.** Цена, расстояние до цели в процентах, статус актива. Обновление каждую секунду. Строка, где цель достигнута, подсвечивается красным.
- **График.** История цены выбранного актива и пунктирная линия цели.
- **Алерты в трёх местах.** Журнал на странице, всплывающее окно и системное уведомление Windows.

## Архитектура и роли

| Модуль | Участник | Задачи |
|---|---|---|
| Сеть | Студент 1 | Опрос Binance REST API, потокобезопасная очередь котировок `Quote`, учёт лимитов запросов |
| Ядро и БД | Студент 2 | SQLite (пользователи и портфели), проверка целей, генерация алертов, сервисы `AuthService` и `PortfolioService` |
| Интерфейс | Студент 3 | C++-сервер на `localhost`, веб-страница: таблица, график, журнал, уведомления |

Модули общаются только через заранее согласованные интерфейсы (`core_api/`). Поэтому части разрабатываются параллельно, а интерфейс проверен на мок-ядре ещё до готовности остальных модулей.

## Технические решения
- **Многопоточность.** Сеть и ядро работают в отдельных потоках (`std::thread`), данные между ними передаются через структуры под `std::mutex`. Потоки ждут через `std::condition_variable` и не нагружают процессор.
- **Безопасная доставка алертов.** Колбэк `onAlert` вызывается из потока ядра и только кладёт алерт в потокобезопасную ленту. Браузер забирает алерты новее своего курсора, поэтому каждый алерт доходит ровно один раз.
- **Один исполняемый файл.** Статическая сборка весит 3,6 МБ и запускается без установки. Полная сборка портативным компилятором GCC (w64devkit) занимает около 25 секунд.

**Стек:** C++17, cpp-httplib, SQLite, Binance REST API, HTML/CSS/JS, GCC (w64devkit).

## План развития

2. Получать котировки по WebSocket Binance вместо опроса.
3. Добавить алерты на рост цены, а не только на падение.
4. Добавить ИИ-анализ, который отличает обычный рыночный шум от аномального обвала с учётом волатильности.
