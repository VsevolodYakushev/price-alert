# Price Alert

Уведомления о падении цены криптоактивов на бирже Binance. Курсовой проект на C++17 команды из трёх человек.

C++-программа поднимает локальный сервер на `localhost:8080`, интерфейс открывается в браузере. Вы добавляете тикеры (`BTCUSDT`, `ETHUSDT`…) и задаёте цель. Когда цена опускается до цели, алерт появляется в журнале, во всплывающем окне на странице и в системном уведомлении Windows.

## Запуск

```bat
git clone https://github.com/VsevolodYakushev/price-alert.git
cd price-alert
run.bat
```

При первом запуске `build.bat` сам скачает портативный компилятор GCC (w64devkit, около 65 МБ) и соберёт `PriceAlert.exe` примерно за 25 секунд. Затем откроется браузер. Устанавливать ничего не нужно.

Демо-вход: **`demo` / `demo123`**, код подтверждения **`123456`**.
